# Экспорт комментариев Instagram и TikTok

[English](README.md) | Русский

Расширение Manifest V3 для Chromium-браузеров выгружает данные текущего Instagram Reel или TikTok-видео:

- никнейм автора;
- описание ролика;
- все доступные на странице комментарии;
- ответы с сохранением иерархии;
- кликабельные ссылки на профили комментаторов и авторов ответов.

Результат автоматически скачивается как Markdown-файл.

## Установка для разработки

1. Откройте `chrome://extensions` в Chrome, Edge, Brave или другом Chromium-браузере.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку этого репозитория.
5. Перезагрузите уже открытые вкладки Instagram и TikTok.

## Использование

1. Авторизуйтесь в Instagram или TikTok в браузере.
2. Откройте нужное видео:
   - Instagram: отдельную страницу Reel (`/reel/.../` или `/reels/.../`) либо ролик в ленте `/reels/`;
   - TikTok: отдельную страницу вида `/@username/video/id`. На отдельной странице результат наиболее надёжен.
3. Нажмите иконку расширения, затем кнопку **Скачать отчёт**.
4. Дождитесь окончания сбора. Во время загрузки комментариев страница показывает прогресс и кнопку отмены.

Расширение раскрывает доступные кнопки загрузки комментариев и ответов, прокручивает панель и останавливается после нескольких циклов без новых данных. Сборщик TikTok использует атрибуты `data-e2e` и резервные DOM-эвристики.

## Формат отчёта

```md
# Instagram Reel — @author

- **Ссылка:** https://www.instagram.com/reel/SHORTCODE/
- **Автор:** @author
- **Дата экспорта:** 05.08.2026, 18:50 GMT+3
- **Комментариев:** 3

## Описание

> Описание ролика

## Комментарии

- **[@commenter](https://www.instagram.com/commenter/)** · 05.08.2026, 17:10 GMT+3
  > Комментарий
  - **[@reply_author](https://www.instagram.com/reply_author/)** · 05.08.2026, 17:15 GMT+3
    > Ответ
```

## Ограничения

- Расширение читает DOM страницы. Instagram и TikTok могут изменить разметку, после чего селекторы потребуется обновить.
- В отчёт попадают только комментарии, доступные текущему аккаунту в веб-интерфейсе. Скрытые, удалённые, ограниченные или не загруженные платформой данные получить нельзя.
- Обработка видео с большим числом комментариев может занять несколько минут. Лимит циклов не позволяет сборщику работать бесконечно.
- Отдельные страницы Reel и TikTok-видео дают наиболее надёжный результат.

Обрабатывайте только те данные, к которым у вас есть законный доступ. Учитывайте правила платформ и требования к персональным данным.

## Структура проекта

- `manifest.json` — конфигурация Manifest V3;
- `icons/` — иконки 16, 32, 48 и 128 px;
- `popup.html`, `popup.css`, `popup.js` — интерфейс расширения;
- `content.js` — загрузка и разбор комментариев Instagram;
- `tiktok.js` — загрузка и разбор комментариев TikTok;
- `report.js` — генератор Markdown-отчёта;
- `tests/report.test.js` — тесты отчёта и иерархии.

## Проверка

Для проверки синтаксиса и запуска тестов нужен Node.js:

```bash
node --check popup.js
node --check content.js
node --check tiktok.js
node --check report.js
node --test tests/report.test.js
```
